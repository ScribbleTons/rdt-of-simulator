# rdt-of-simulator
Resilient Digital Twin Operational Framework Simulator (RDT-OFS)

Suggested demonstration sequence

1. Start with normal production.
2. Trigger grid outage.
3. Let the audience observe the thermal and power warnings.
4. Show the prediction stage.
5. Demonstrate the transition to dynamic derating.
6. Introduce internet loss to demonstrate edge continuity.
7. Restore grid power and demonstrate recovery.
